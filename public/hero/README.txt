AFFICHES DU SLIDER (HERO)
=========================

Déposez ici vos affiches photo, puis renseignez le champ `image` de chaque
slide dans src/components/common/Hero.jsx (ex: image: '/hero/slide-1.jpg').

DIMENSIONS RECOMMANDÉES
-----------------------
- Desktop (master)  : 2400 x 900 px   (ratio 8:3)  <-- format d'affichage du slider
- Export retina     : déjà couvert par 2400 px de large (affichage ~1200 px)
- Format            : WebP de préférence (sinon JPG)
- Poids             : < 400 Ko par image (optimisées)

MOBILE (optionnel mais recommandé)
----------------------------------
Sur mobile le slider est plus haut (ratio 4:5). Si vous intégrez du texte
dans l'image, prévoyez une version mobile : 1080 x 1350 px (4:5).

ZONE DE SÉCURITÉ
----------------
Le texte du slider s'affiche à GAUCHE (voile sombre dégradé de la gauche).
- Si vous laissez le texte du site : placez le produit/visuel fort à DROITE,
  gardez la gauche assez sombre/épurée.
- Si vous intégrez tout le texte dans l'image : videz le texte du slide
  (title/subtitle) et laissez seulement l'image.

Gardez les éléments importants dans les 80% centraux (les bords peuvent être
rognés selon la taille d'écran).
